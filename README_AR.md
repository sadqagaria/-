# نبض القاهرة — الإصدار 7

تطبيق HTML/PWA متجاوب، ومعه مشروع Android جاهز للبناء وودجت حقيقي للشاشة الرئيسية.

## واجهة الإصدار 7

الصفحة الرئيسية تعرض فقط:

- الساعة بالعقارب أو بالشكل الرقمي.
- درجة الحرارة وحالة الطقس الحالية.
- الصلاة القادمة ووقتها والوقت المتبقي.
- سعر الدولار الأمريكي مقابل الجنيه.
- سعر الذهب عيار 21.
- سعر أونصة الذهب.
- طقس اليوم فقط.
- موقع الوقت الحالي بين مواقيت الصلاة.

جميع التفاصيل الأخرى مخفية افتراضيًا، ولا تظهر إلا بعد الضغط على الزر المخصص. صفحة الإعدادات لا تظهر داخل الرئيسية، وتُفتح من زر الترس فقط.

## الآلة الحاسبة

تم ترتيبها من اليمين وإضافة:

- الجذر التربيعي `√`.
- الأس `xʸ`.
- الأقواس `( )`.
- زر `00`.
- زر `000`.
- النسبة المئوية والعمليات الأساسية.

## تشغيل نسخة الويب

شغّل المشروع عبر خادم محلي أو ارفعه إلى GitHub Pages:

```bash
python -m http.server 8080
```

ثم افتح:

```text
http://localhost:8080
```

## النشر على GitHub Pages

يوجد Workflow جاهز باسم **Deploy Cairo Pulse to GitHub Pages**. اجعل مصدر GitHub Pages هو **GitHub Actions** ثم ارفع الملفات إلى فرع `main` أو `master`.

## بناء APK عبر GitHub Actions

1. ارفع المجلد كاملًا إلى مستودع GitHub.
2. افتح تبويب **Actions**.
3. شغّل Workflow باسم **Build Cairo Pulse APK**.
4. حمّل Artifact باسم:

```text
cairo-pulse-v7-apk
```

## الودجت على Android

بعد تثبيت APK، افتح قائمة Widgets في الهاتف وابحث عن **نبض القاهرة — الطقس والصلاة**. يعرض الودجت درجة الحرارة، حالة الطقس، الصلاة القادمة، وقتها، والوقت المتبقي.

## أهم الملفات

- `index.html`: واجهة الويب.
- `styles.css`: التصميم والخلفية الديناميكية.
- `app.js`: البيانات والمنطق والحاسبة والتنقل.
- `cairo_pulse_standalone_v7.html`: نسخة HTML مدمجة في ملف واحد.
- `android-native`: مشروع Android والودجت.
- `.github/workflows`: النشر وبناء APK.
