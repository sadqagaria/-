# SATELLITE WORLD TV — Android Receiver (v0.2.0)

**مشروع Android متكامل للبناء عبر GitHub Actions مع دليل قنوات وفلاتر قمر صناعي موثّقة.**

تطبيق IPTV/Internet Radio مفتوح المصدر، بواجهة ريسيفر، يعتمد على Android/Kotlin + Jetpack Compose + Media3/ExoPlayer، ويستورد قوائم تلفزيونية وإذاعية علنية من مشاريع GitHub. لا يأتي مع اشتراك مدفوع ولا يَعِد بتشغيل جميع القنوات الفضائية.

## بناء APK من GitHub Desktop بدون كتابة كود

هذه الحزمة تتضمن `.git` لتعمل كمستودع Git محلي جاهز. يُفضّل استخراج المجلد كاملًا في مجلد قصير الاسم على Windows.

1. افتح **GitHub Desktop**.
2. اختر **File → Add Local Repository → Choose** وحدّد مجلد `SatelliteWorldTV` بعد فك الضغط، وليس ملف ZIP.
3. اضغط **Publish repository** واختر اسم `SatelliteWorldTV` (ويمكن اختيار Private).
4. افتح المستودع على موقع GitHub، ثم تبويب **Actions**، واختر **Build Android APK**. التشغيل يحدث تلقائيًا عند نشر الفرع `main`. إذا لم يبدأ، اختر **Run workflow**.
5. بعد إكمال المهمة بعلامة خضراء، افتح المهمة وانزل إلى **Artifacts** ثم حمّل `SatelliteWorldTV-debug-apk`.
6. فك ضغط artifact وستجد `app-debug.apk`؛ انقله لهاتف Android وثبّته. هذه نسخة تطوير Debug قابلة للتثبيت، وليست إصدار متجر Google Play.

**مهم:** لم يحدث بناء APK في بيئة التأليف؛ يلزم نجاح GitHub Actions أولًا. في حالة فشل البناء راجع سجل الخطأ في خطوة `JVM unit tests` أو `Build installable debug APK`.

## تشغيل محلي للمطورين

- Android Studio مع Android SDK API 35، JDK 17، Gradle 8.9.
- افتح المجلد باعتباره Android Gradle Project.
- نفّذ `gradle :app:testDebugUnitTest` ثم `gradle :app:assembleDebug`.
- الناتج `app/build/outputs/apk/debug/app-debug.apk`.
- الحد الأدنى: Android 8.0 (API 26).

## ما تم إنشاؤه في هذه النسخة

- واجهة بنمط ريسيفر مع وضع مناسب للشاشات الواسعة وشاشات الموبايل.
- مشغّل Media3 للفيديو والصوت، وتغيير القنوات بأزرار Channel +/-، والأرقام على الريموت، وتحكم لمس.
- عرض قائمة القنوات وشعاراتها، بحث، مجموعات مصر/الخليج/العرب/أوروبا/الإنجليزية/العالم، قائمة مفضلة، وتذكّر آخر قناة.
- بطاقات للأقمار Nilesat 7°W وBadr/Arabsat 26°E وHot Bird 13°E **عندما توجد بيانات قمر موثّقة**.
- مصدر تلفزيون عبر الإنترنت من `iptv-org`، ومصدر راديو من `verified-radio-streams`، يتم تحميلهما عند التشغيل لأول مرة، مع التخزين محليًا وإعادة المزامنة كل 24 ساعة عبر WorkManager.
- استيراد M3U وCSV وملفات `userbouquet*.tv`/`*.radio` (قنوات DVB الفضائية تُعرض كدليل فقط بدون اختراع روابط بث)، وترتيب يدوي للمداخل المستوردة.
- استيراد XMLTV اختياري لدليل البرنامج الحالي والتالي عند وجود `tvg-id` مطابق.
- نافذة عرض مصغّرة PiP على الأجهزة الداعمة.
- استرجاع البيانات القديمة إذا فشل تنزيل قائمة جديدة. القنوات بدون رابط تشغيل تُعرض باعتبارها دليلًا فقط.

## كيف تستورد ترتيب الريسيفر الخاص بك؟

من القائمة العلوية اختر رمز **الملف** ثم افتح:

- ملف M3U/M3U8 خاص بك.
- CSV بعناوين أعمدة `name,url,satellite,number,group,radio,tvg-id`؛ يمكن ترك `url` فارغًا إذا أردت دليل قنوات فقط.
- `userbouquet*.tv` أو `*.radio` من Enigma2؛ تُستخرج أسماء القنوات وترتيبها وموضع القمر من بيانات الخدمة إن توفرت، لكنها لا تستطيع تحويل البث الفضائي المشفّر إلى بث إنترنت.

بعد الاستيراد ستجد الملفات في تبويب **قائمتي**. اختر أسهم الترتيب بجوار القناة لتغيير ترتيبها. اضغط زر القلب لإضافتها إلى المفضلة. زر التقويم يستورد XMLTV من ملف إذا توفر.

## ملاحظات وحدود النسخة 0.1

- **لم يُنشأ APK محلي** لعدم وجود Android SDK/Gradle وعدم توافر اتصال تنزيل بهذه البيئة. يخرج APK من GitHub Actions بعد نجاح البناء.
- **لم يُتحقق من تشغيل القنوات على جهاز Android** أو صلاحية كل رابط من البيئة الحالية؛ الاختبارات المحلية شملت قارئ ملفات القنوات فقط.
- لا يضمن المشروع **1000 قناة على كل قمر**، ولا يربط القنوات بالأقمار اعتمادًا على جنسيتها. تطابق ترتيب الريسيفر يتطلب استيراد قائمته الأصلية.
- استيراد ملفات `lamedb` منفردة، أو `bouquets.tv` بوصفها قوائم ملفات متعددة، **غير مكتمل** في هذه النسخة؛ يدعم استيراد ملف `userbouquet*.tv` الفردي فقط.
- **لم تُنفّذ بعد** خدمات راديو تعمل بالخلفية بعد إنهاء التطبيق، وحسابات المستخدمين، والدعم الكامل لميزة parental PIN، والتحقق القانوني الآلي لكل رابط، واختيار جودة مخصصة لكل قناة، وإعدادات لغات متعددة.
- يعرض قوائم قنوات مختارة حسب الدولة، لا حسب التردد. ترددات DVB ليست فيديوهات قابلة للتشغيل عبر IP تلقائيًا.
- HTTP البسيط مفعل لأن بعض المصادر ما زالت تستخدم HTTP، ويُفضل اعتماد HTTPS عندما يكون متاحًا.
